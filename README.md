# YFG ACC-WEB — نسخهٔ وب ماژول حسابداری YFG ERP

وب‌اپلیکیشن Next.js برای ماژول حسابداری YFG ERP با اتصال مستقیم به SQL Server.

## نسخهٔ فعلی: v2.7.1
- **v2.7.1:** نوار «پنجره‌های باز» در ساید بار پایین — هر چیپ اکنون دکمهٔ ضربدر (✕) برای بستن پنجره دارد.
- **v2.7.0:** پنجرهٔ انتخاب معین با جست‌وجو/مرتب‌سازی و پر شدن خودکار کد کل از والد.
- **v2.6.0:** ساید بار بالا برای ماژول‌ها + ساید بار راست برای تب‌ها و فیلدها + میزکار چندپنجره‌ای.

## ساختار بستهٔ انتشار (Release Assets)
```
ACCWeb-<ver>.zip
├── app/            برنامهٔ Next.js standalone (شامل node_modules)
├── node/           Node.js پرتابل ویندوزی
├── sql/            اسکریپت‌های دیتابیس (01 تا 12 — افزایشی و Idempotent)
├── docs/           مستندات و یادداشت‌های انتشار
├── START-ACC.bat   اجرا روی پورت 5031 + نصب آپدیت معلق
├── SETUP-ACC.cmd   ایجاد دیتابیس acc (نیازمند sa)
├── setup.js        نصب‌کنندهٔ دیتابیس
├── update.ps1      نصب آپدیت معلق
└── fix-update.ps1  نسخهٔ تعمیری نصب آپدیت
```

## آپدیت خودکار
سرویس هنگام راه‌اندازی، آخرین Release این مخزن را بررسی می‌کند؛ اگر نسخهٔ جدیدتری موجود باشد بسته را دانلود و پس از خروج سرویس از طریق `update.ps1` نصب می‌کند.
